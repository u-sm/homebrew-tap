# u-sm/homebrew-tap

Homebrew casks for [iMiqaat](https://github.com/u-sm/imiqaat), salah times on your Mac's Lock Screen.

```sh
brew install --cask u-sm/tap/imiqaat
```

iMiqaat's releases are ad-hoc signed and not yet notarized, so macOS stops the app the first time you open it. Open **System Settings › Privacy & Security**, scroll down and click **Open Anyway** next to iMiqaat.

`Casks/imiqaat.rb` is updated automatically by iMiqaat's release workflow.
